# Environment Spritesheets — Описание сетки и содержимого

Базовая сетка проекта: **16x16 px** (`GameConfig.TileSize = 16`).

---

## walls_floor.png — 208x368

**Сетка: 16x16**, 13 колонок x 23 ряда.

| Ряды | Описание |
|------|----------|
| 0-5 | **Стены** — автотайлинг: верхние грани, боковые, внутренние/внешние углы. Тёмный камень. Полный набор для 4-bit или blob autotiling |
| 6-8 | **Полы** — базовые варианты пола (светлый камень), несколько вариаций для рандомизации |
| 9-13 | **Стены-фасады** — высокие стены (2-тайла в высоту): фронтальная поверхность стен с текстурой кирпичной кладки |
| 14-18 | **Арки и проёмы** — большие стеновые элементы 2x2 и 3x2: арочные проходы, решётки, ворота |
| 19-22 | **Декоративные стены** — вариации крупных стеновых блоков с арками, колоннами |

**Применение:** основной тайлсет для `TileRenderSystem` — замена цветового рендера на спрайтовый. Автотайлинг стен + рандомный выбор вариаций пола.

---

## Objects.png — 384x96

**Сетка: 16x16**, 24 колонки x 6 рядов.

| Область | Содержание |
|---------|-----------|
| Col 0-1 | **Лестница каменная** (спуск/подъём) — 16x32 (1x2 тайла) |
| Col 2-3 | **Лестница деревянная** (приставная) — 16x32 |
| Col 4-8 | **Бочки** — целые и разбитые, несколько вариантов |
| Col 9-13 | **Камни/обломки** — мелкие и крупные декоративные камни, кучки щебня |
| Col 14-18 | **Ящики/коробки** — деревянные ящики, стопки, одиночные |
| Col 19-21 | **Мешки** — мешки с добром, разных размеров |
| Col 22-23 | **Мелкие объекты** — колонна/столб, факел на подставке |

**Применение:** `DecorationPainter` для декора комнат, `ItemRenderSystem` для визуала лута на земле, лестницы для `StairDown`.

## doors_lever_chest_animation.png — 160x192

**Сетка: 16x16**, 10 колонок x 12 рядов. Анимированные объекты.

| Ряды | Описание |
|------|----------|
| 0-3 | **Двери** — каменные/деревянные арочные проёмы. Кадры анимации открытия (32x32, 2x2 тайла). ~4 кадра на дверь |
| 4-7 | **Сундуки** — 3 типа (простой, железный, золотой). Анимация открытия ~4-5 кадров. Размер кадра 16x16 |
| 8-9 | **Сундуки (продолжение)** — открытые состояния |
| 10-11 | **Рычаги/levers** — анимация переключения (вкл/выкл), ~4 кадра |

**Применение:** `ChestSystem` — анимация открытия сундуков. Двери — для механики запертых комнат. Рычаги — для ловушек/секретов.

## fire_animation.png — 176x288

**Сетка: ~32x48** (2x3 тайла на кадр), 4 варианта огня.

- **Настенный факел** (большой, с подставкой) — 32x48, ~4 кадра анимации
- **Костёр/жаровня** — 32x48, ~4 кадра
- 6 рядов x 4 колонки — несколько вариантов с разным свечением

**Применение:** замена `DecorationType.Torch` — анимированные факелы на стенах/в комнатах.

---

## fire_animation2.png — 96x192

**Сетка: 16x16**, маленькие огоньки. 6 колонок x 12 рядов.

- **Мелкие огоньки/свечи** — компактная версия огня (16x16 или 16x32)
- ~4-6 кадров анимации на вариант

**Применение:** мелкие свечи на столах, слабое освещение, ambiance-декор.

---

## trap_animation.png — 144x400

**Сетка: 16x16**, 9 колонок x 25 рядов.

| Область | Описание |
|---------|----------|
| Ряды 0-9 | **Шипы из пола** — тонкие точечные паттерны, ~6 кадров: убран -> частично выдвинут -> полностью выдвинут |
| Ряды 10-24 | **Шипы (крупные)** — более заметные вертикальные шипы, тот же цикл. Размеры: 16x16 и 32x32 |

**Применение:** ловушки на полу — `TrapSystem`. Анимация: idle -> activate -> retract.

---

## decorative_cracks_floor.png — 128x240

**Сетка: 16x16**, 8 колонок x 15 рядов.

- **Трещины на полу** — оверлеи поверх базового тайла пола
- Формы: горизонтальные, вертикальные, перекрёстные, точечные
- Полупрозрачные, накладываются поверх

**Применение:** `DecorationPainter` / `TileRenderSystem` — рандомные трещины на полу для разнообразия.

---

## decorative_cracks_walls.png — 128x512

**Сетка: 16x16**, 8 колонок x 32 ряда.

- **Трещины на стенах** — оверлеи для стеновых тайлов
- Вертикальные, горизонтальные разломы, выщербины
- Привязаны к ориентации стены (верхняя грань, боковые, фронтальная)

**Применение:** накладывается на стены из `walls_floor.png` для aged/damaged вида.

---

## decorative_cracks_coasts_animation.png — 256x336

**Сетка: 16x16**, 16 колонок x 21 ряд. Анимированный.

- **Береговые трещины / кромка воды** — анимированные оверлеи для перехода вода<->пол
- ~4 кадра анимации (4 колонки на вариант)
- Полный автотайлинг набор: углы, стороны, внутренние углы

**Применение:** декор для водных тайлов — анимированная кромка воды.

---

## Water_coasts_animation.png — 352x448

**Сетка: 16x16**, 22 колонки x 28 рядов. Анимированный автотайлинг.

- **Берег воды** — полный набор coast-тайлов (вода у пола)
- Autotiling: все комбинации сторон и углов
- ~4 кадра анимации на тайл (колонки сгруппированы по фреймам)

**Применение:** `TileType.Water` — анимированные береговые переходы.

---

## water_detilazation_v2.png — 688x576

**Сетка: ~32x32** (2x2 базовых тайла), анимированная текстура воды.

- **Поверхность воды** — волнистые линии/рябь
- 3 колонки x ~9 рядов анимационных кадров
- Тайлится бесшовно

**Применение:** анимация поверхности воды, рисуется под coast-тайлами.
