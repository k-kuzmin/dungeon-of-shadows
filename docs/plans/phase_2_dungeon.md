# Фаза 2: Dungeon

## Описание

Процедурная генерация подземелий через BSP-алгоритм, система комнат и коридоров, туман войны (FOV) и мини-карта. После этой фазы каждый запуск игры будет создавать уникальный этаж подземелья.

- [ ] Масштабирование: +5×5 на каждые 5 этажей

### 2.2 Комнаты
- [ ] Структура `Room` (прямоугольник, тип, содержимое)
- [ ] 8–14 комнат на этаж
- [ ] Типы комнат: обычная, стартовая (spawn), лестница вниз

- [ ] Декор: факелы, трещины, кости, лужи (не влияют на проходимость)

- [ ] L-образные коридоры между смежными комнатами BSP-дерева
- [ ] Ширина 1–2 тайла
- [ ] Двери на входах в комнаты (опционально)

- [ ] Базовый радиус видимости: 7 тайлов

- [ ] Стены блокируют луч, но сами видимы
- [ ] Обновление каждый кадр
- [ ] Рендер: неизвестный — чёрный, исследованный — затемнение 60%
