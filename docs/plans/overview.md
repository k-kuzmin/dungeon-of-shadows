## Граф зависимостей

```
Фаза 1 (Core)
  └── Фаза 2 (Dungeon)
        └── Фаза 3 (Combat)
              ├── Фаза 4 (Items)
              │     └── Фаза 5 (Magic)
              │           └── Фаза 6 (Progression)
              └── Фаза 7 (Bosses) ← зависит от 2, 3, 4, 5
Фаза 8 (Art) ← зависит от всех предыдущих
Фаза 9 (Polish) ← зависит от всех предыдущих
```

## Структура каждого плана

- **Описание** — что делается в фазе
- **Статус** — текущий прогресс (Не начато / В работе / Завершено)
- **Что нужно сделать** — чеклист задач с `[ ]`
- **Что сделано** — заполняется по мере выполнения
- **Зависимости** — какие фазы должны быть завершены перед началом
