# Фаза 4: Items

## Описание

Система предметов: лут с врагов и из сундуков, инвентарь, экипировка (оружие, броня, амулет, кольцо), система редкостей, зелья и быстрые слоты.

## Статус: В работе (MVP реализован, есть остаток)

---

## Что нужно сделать

### 4.1 Базовая система предметов
- [x] Структура `Item` (через `ItemDefinition` + `ItemStack`)
- [x] Типы: Weapon, Armor, Amulet, Ring, Potion, Scroll
- [x] JSON-конфиги для определения предметов (`assets/data/items.json`)
- [x] Загрузка определений предметов из JSON

### 4.2 Система редкостей
- [x] Common (белый) — базовые характеристики
- [x] Uncommon (зелёный) — +1 случайный бонус
- [x] Rare (синий) — +2 бонуса, улучшенная база
- [x] Epic (фиолетовый) — +3 бонуса, улучшенная база
- [x] Legendary (золотой) — процедурно усиленный предмет
- [x] Генерация случайных бонусов при создании предмета

### 4.3 Лут и дроп
- [x] Таблица дропа врагов (зависит от типа врага и этажа)
- [x] Дроп при смерти врага (предмет падает на пол)
- [x] Сундуки в комнатах (гарантированный лут)
- [ ] Золото (валюта)
- [x] Подбор предметов клавишей E

### 4.4 Инвентарь
- [x] Компонент `Inventory` (сетка предметов, ограничение по слотам)
- [x] Экран инвентаря (клавиша I, пауза игры)
- [ ] Отображение предметов в сетке с иконками (сейчас текст/цветовые маркеры)
- [x] Tooltip с описанием и статами предмета
- [x] Сравнение с экипированным предметом

### 4.5 Экипировка
- [x] Слоты: Weapon, Armor, Amulet, Ring (2 слота Ring)
- [x] Экипировка / снятие предметов
- [x] Применение бонусов экипировки к статам игрока
- [x] Визуальное отображение слотов на экране инвентаря

### 4.6 Быстрые слоты
- [x] 4 слота (клавиши 1–4)
- [x] Назначение зелий/свитков в слоты
- [x] Использование с кулдауном
- [x] HUD-отображение быстрых слотов (низ экрана)

### 4.7 Зелья
- [x] Health Potion — восстанавливает HP
- [ ] Mana Potion — восстанавливает MP
- [ ] Визуальный эффект при использовании

## Что сделано
- Реализован `assets/data/items.json` и загрузка определений предметов.
- Реализованы типы/редкости/бонусы предметов и процедурная генерация.
- Реализован дроп с врагов и сундуков, подбор ближайшего предмета по `E`.
- Реализованы `Inventory`, `Equipment`, `QuickSlots`, `ItemOnGround`, `Chest`.
- Реализован экран инвентаря `I`: сетка, tooltip, compare, drag/drop.
- Реализованы экипировка/снятие с корректным применением статов.
- Реализовано использование расходников из быстрых слотов с кулдаунами по типу.
- Проведены и исправлены high/medium замечания по качеству и производительности.
