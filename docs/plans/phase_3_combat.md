# Фаза 3: Combat

## Описание

Реалтайм-боёвая система: атака мечом (дуга 90°), первые 3 типа врагов с AI-поведением, система дэша с i-frames, полоски HP и базовые формулы урона.

## Что нужно сделать

### 3.1 Атака мечом
- [ ] Дуга 90° перед игроком в направлении последнего движения
- [ ] Анимация атаки: 0.25с
- [ ] Кулдаун: 0.3–0.8с (зависит от оружия)
- [ ] Проверка попадания: пересечение сектора с hitbox-ами врагов
- [ ] Визуальный эффект слэша

### 3.2 Формулы урона
- [ ] Физический урон: `(ATK × weaponMult) − (target.DEF × 0.7) + random(−1, +2)`
- [ ] Крит: `damage × 1.8`, шанс = `baseCrit (5%)`
- [ ] Числа урона над головой (частицы)
- [ ] Компонент `Health` (HP, maxHP)
- [ ] Компонент `Stats` (ATK, DEF, INT, SPD, Crit)

### 3.3 Dash (рывок)
- [ ] Клавиша: L / Shift
- [ ] i-frames: 0.2с неуязвимости
- [ ] Кулдаун: 1.0с
- [ ] Визуальный след дэша

### 3.4 Враги — базовые типы
- [ ] **Rat** (HP: 8, ATK: 2, DEF: 0) — бежит к игроку, убегает при HP < 30%
- [ ] **Goblin** (HP: 15, ATK: 4, DEF: 1) — стрейфит, атакует сбоку
- [ ] **Skeleton** (HP: 20, ATK: 6, DEF: 2) — медленный, патрулирует, сильный удар

### 3.5 AI-система
- [ ] AISystem: обработка поведения врагов
- [ ] Обнаружение игрока (в радиусе видимости)
- [ ] Состояния: Idle, Patrol, Chase, Attack, Flee
- [ ] Навигация к игроку (простой pathfinding или прямое движение)
- [ ] Атака по кулдауну при достижении дистанции

### 3.6 Скейлинг врагов
- [ ] Формула: `stat = base × (1 + floor × 0.15)`
- [ ] Количество в комнате: 1–3 (этаж 1–4)
- [ ] Спавн врагов при входе в комнату

### 3.7 HUD — полоски HP
- [ ] Полоска HP игрока (верх экрана)
- [ ] Полоски HP врагов (над головой)
- [ ] Визуальная обратная связь при получении урона (мигание, screen-shake)

### 3.8 Смерть
- [ ] Анимация смерти врагов
- [ ] Удаление мёртвых сущностей
- [ ] Смерть игрока → состояние Dead (пока без экрана смерти)
