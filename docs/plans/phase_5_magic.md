# Фаза 5: Magic

## Описание

Система магии: ресурс маны, 6 заклинаний с различными механиками (проджектайлы, AoE, телепорт, хил), нахождение заклинаний через свитки, слоты заклинаний.

### 5.4 Заклинания

#### Magic Bolt (3 MP)
- [ ] Проджектайл по направлению взгляда
- [ ] Урон = INT × 2
- [ ] Визуальный эффект (светящийся шар)

#### Fireball (8 MP)
- [ ] Проджектайл → взрыв AoE 3×3 тайла при столкновении
- [ ] Урон + эффект поджога (3 тика урона)
- [ ] Визуал: огненный шар + взрыв

#### Frost Nova (6 MP)
- [ ] AoE вокруг игрока
- [ ] Замедление 60% на 3с
- [ ] Визуал: волна льда

#### Chain Lightning (10 MP)
- [ ] Молния прыгает между 3–5 врагами
- [ ] Поиск ближайших целей в радиусе
- [ ] Визуал: цепная молния

#### Shadow Step (5 MP)
- [ ] Телепорт на 5 тайлов в направлении движения
- [ ] i-frames 0.3с
- [ ] Проверка на проходимость точки назначения
- [ ] Визуал: теневой эффект

#### Heal (7 MP)
- [ ] Восстановление 20 + INT × 1.5 HP
- [ ] Визуал: зелёное свечение
